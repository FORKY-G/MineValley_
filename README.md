# Minevalley | 제작법 모음

기술대와 가공대 제작법을 통합한 GitHub Pages용 웹사이트입니다.

- 기술대: 65개
- 가공대: 42개
- 전체: 107개

## GitHub에 업데이트하기

기존 저장소의 `index.html`, `app.js`, `recipes.json`, `README.md`를 새 파일로 교체하세요. `style.css`와 `.nojekyll`은 유지해도 됩니다. 기존에 업로드한 `images` 폴더는 **삭제하지 마세요**. 새 가공대 이미지 `p-1.png`, `p-2.png` 등을 `images/`에 추가하세요.

이 ZIP에는 기존에 사용자께서 GitHub에 직접 올린 이미지 파일이 들어 있지 않습니다. ZIP을 그대로 전체 덮어쓰면서 이미지 폴더를 삭제하지 않도록 주의하세요.

## 기능
전체 제작법 / 기술대 / 가공대 / 즐겨찾기 필터, 이름과 재료 검색, 수량별 계산, 하위 제작법 자동 연결 및 원재료 계산.

## 배포
GitHub 저장소 `Settings → Pages → Deploy from a branch → main / (root)`를 선택합니다.
