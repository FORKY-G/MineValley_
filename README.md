# Minevalley | 기술자 제작대

스타듀밸리 × 마인크래프트 스타일의 제작법 검색 사이트입니다.

## 배포 방법
1. GitHub에 공개 저장소를 만듭니다.
2. ZIP을 풀고 **안의 파일 및 images 폴더**를 저장소 최상위에 업로드합니다.
3. Settings → Pages → Deploy from a branch → main / (root) → Save를 선택합니다.
4. `https://사용자아이디.github.io/저장소이름/`에 접속합니다.

## 아이템 이미지 관련 중요 사항
새로 제공된 `일반기술대(2).xlsx`에는 실제 삽입된 이미지 파일이나 이미지 URL이 없습니다. A열에 `t-1`부터 시작하는 **파일이름 텍스트만** 있습니다. 따라서 현재 버전은 이미지가 없으면 임시 아이콘을 보여줍니다.

실제 PNG 파일을 `images/t-1.png`, `images/t-2.png`와 같이 저장하면 사이트가 자동으로 해당 이미지를 표시합니다. 엑셀 A열 파일명과 동일해야 합니다. 원본 이미지가 따로 있다면 PNG 파일이나 이미지가 삽입된 엑셀을 보내주세요.

## 기능
아이템 및 재료명 검색, 즐겨찾기, 수량별 재료 계산, 하위 제작 재료 합계. 카테고리 분류는 제거했습니다.

## 데이터
`recipes.json`에 엑셀의 65개 제작법을 반영했습니다. 엑셀에 없는 제작법은 임의로 추가하지 않았습니다.

## 로컬 실행
`python -m http.server 8000` 실행 후 `http://localhost:8000`에 접속합니다.
